# VR Cam

Live camera with about 200 filters and effects (colour grades, duotones, vision simulations, warps, kaleidoscopes, halftone, ASCII, thermal, trails, cartoon, glitch and more), Cardboard viewer QR calibration, and a side-by-side VR mode for Cardboard-style headsets.

**VR mode:** tap = next filter, double tap = photo, long press = rotate 180, Back = normal view.
**Normal view:** Filter dropdown (top-left), Flip camera, 180, photo button, VR.

**Cardboard:** normal view > Cardboard menu > scan the QR code on your viewer.

Photos go to Pictures/VRCam. Android 10+ (minSdk 29).

## Build
- **Android Studio:** File > Open this folder, let it sync, press Run.
- **No install:** push to a GitHub repo; the Actions workflow builds the APK (Artifacts of the run).
