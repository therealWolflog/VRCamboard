# VR Cam

Live camera with colour filters and a side-by-side VR mode for Cardboard-style headsets.

**VR mode controls (the screen is the controller):** tap = next filter, double tap = take photo, long press = flip the picture 180°, Back = normal view with buttons (which also has a 180° button).
Photos are saved to Pictures/VRCam. Android 10+ (minSdk 29).
